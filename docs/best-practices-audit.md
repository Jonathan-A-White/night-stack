# NightStack best-practices audit

Written 2026-10-09 at commit 3095958 (version 1.0.1). Docs only: no source file changed, no behaviour changed. It answers
the Governor's word (Postern general, 2026-10-09 18:37Z): bring every app up to the best practices we have spoken about.

What it audits against: the one-line-per-rule checklist of the vault's PWA practices
(`seats/builder/pwa-best-practices/checklist.md`, 31 lines) and each section the line points to, plus the rules the
changelog placed on 2026-10-09 (long press to hear, Pause/Resume/Restart on speech, live push-to-talk words, credits follow
removals, the version raised each landing, module boundaries for parallel work, and that day's cache-shape and test-key
licence rules).
`bash docs/check-best-practices-audit.sh` checks the shape of this file and that every file:line it cites exists.

How to read it:

- Status is `pass`, `fail` or `n/a`. A line with several clauses is `fail` when any clause that applies fails; the evidence
  names the clause. `n/a` says why: NightStack has no speech, no pictures, no server and no model, so those rows are
  `n/a`. NightStack is wholly a PWA (React 19, Vite, vite-plugin-pwa, Dexie); no part of it is an Android app or a server.
- Evidence is a `file:line` in this checkout, or a command and what it printed. A line number is where the thing is today.
- Size: **S** is under about 60 changed lines, one sitting; **M** is one Builder session with the gate green; **L** needs
  splitting into stories first. A fix that needs `.github/workflows/` is marked so: a Builder cannot change that folder.
- Commands were run in this checkout after `npm ci`: `npm run build` exits 0 and writes `dist/` with
  `dist/manifest.webmanifest`; the PNG sizes come from `file public/*.png` (180, 192 and 512 px).
