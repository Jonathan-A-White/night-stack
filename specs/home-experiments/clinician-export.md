# Workstream: clinician-export

**Blocked by:** `episode-capture`, `vitals`, `body-measurements`,
`night-tags`. **Optional input:** `samsung-bulk-import` (adds SpO2
nadir / HR peak columns when samples exist). **Runs in parallel with:**
`insights-and-rules`.

Decisions: Q14 (CSV + printable HTML, date range, 14-day default), Q3
(calibration flag in export), Q8 note (free-text experiment notes
column). Research: §10 (download pattern), §11 (metric extractors —
reuse `nightMetrics` if it has merged; otherwise a local copy that
insights-and-rules dedupes).

## Scope

1. `src/services/clinicianExport.ts` — pure:
   - `buildClinicianRows(nights: NightMetricCtx[], readings, samples?)
     → ClinicianRow[]` (one per night, **every** column always
     present, blanks for missing).
   - `toCsv(rows)` — RFC 4180 quoting, `\r\n`, UTF-8 BOM so Excel
     opens it cleanly; header row fixed order.
   - `summaryStats(rows)` — counts for the printable page: nights,
     episodes, adrenergic nights by sodium level × position (a 2×3
     table), mean overnight weight/neck delta by sodium level, flagged
     orthostatic readings count, calibration warnings.
2. `/experiments/export` page: date range (default last 14 nights
   ending today), "Download CSV", "Open printable summary", checkbox
   "Include notes columns" (default on).
3. `/experiments/export/print` page: one A4/Letter page in `@media
   print` styles (light background regardless of theme, black text),
   header with date range and generation time, the summary tables,
   then a compact nights table; a "Print / Save as PDF" button calls
   `window.print()`.
4. Link from Settings › Data Management.

Columns (in order):

```
night_date, watch_sleep_time, watch_wake_time, sleep_score, total_sleep_min, awake_min, avg_hr, min_hr, spo2_avg,
sodium_level, sodium_source, sodium_sources, electrolyte_dose, alcohol, last_meal_time,
position_started, position_at_wake, wired_wake,
pm_weight_lb, am_weight_lb, weight_delta_lb, pm_neck_in, am_neck_in, neck_delta_in,
episode_count, episode_1_time, episode_1_position, episode_1_ecg, episode_1_rhythm, episode_1_lying_bp, episode_1_minutes_to_settle, episode_1_back_to_sleep, episode_1_wired,
episode_2_time, … (up to 3 episodes; extra episodes counted only),
pm_ortho_source, pm_supine, pm_stand1, pm_stand3, pm_sys_drop3, pm_dia_drop3, pm_pulse_rise3, pm_flags, pm_recalibrate,
am_ortho_source, am_supine, am_stand1, am_stand3, am_sys_drop3, am_dia_drop3, am_pulse_rise3, am_flags, am_recalibrate,

```

BP cells are `"S/D (P)"`; the AM row is the reading on the morning
**after** `night_date`, the PM row the evening of `night_date`.

## Non-goals

- PDF generation in code (browser print does it).
- Charts on the printable page beyond tables.
- Any interpretation; the page footer says "Generated by NightStack
  from self-recorded data. Flags follow common thresholds and are not
  a diagnosis."

## Given / When / Then

```gherkin
Feature: CSV

  Scenario: One row per night with every column
    Given 14 nights, 3 with episodes, 10 with PM weight, 6 with AM vitals
    When buildClinicianRows and toCsv run
    Then the CSV has 1 header + 14 data rows
    And every row has the same number of fields as the header

  Scenario: Missing values are blank, not "null" or "undefined"
    Given a night with no vitals and no weight
    Then its vitals and weight cells are empty strings

  Scenario: Quoting
    Given morning_notes containing a comma, a quote and a newline
    Then the field is quoted, inner quotes doubled, and the row still parses back to the same string

  Scenario: Round trip
    Given rows R
    When toCsv(R) is parsed by a minimal CSV reader in the test
    Then the parsed cells equal R's string values (Q18 required test 3)

  Scenario: Calibration flag
    Given a watch PM reading 31 days after calibration
    Then pm_recalibrate is "yes"

  Scenario: Trace columns only when samples exist
    Given no vitalSamples
    Then spo2_nadir_pre_episode is blank
    Given samples around an episode
    Then it holds the nadir percent

Feature: Summary stats

  Scenario: 2x3 adrenergic table
    Given nights: (more, back, episode), (more, side, none), (normal, back, none), (much_more, unknown, wired)
    Then the table counts adrenergic nights per (sodium level × position) cell as more/back 1, more/side 0, normal/back 0, much_more/unknown 1

  Scenario: Mean deltas by sodium level ignore nights without both measurements
    Given two 'more' nights with weight deltas 1.8 and null
    Then mean weight delta for 'more' is 1.8 with n=1

Feature: Page

  Scenario: Default range
    When the export page opens on 2026-09-04
    Then the range is 2026-08-21 to 2026-09-03 (14 nights)

  Scenario: Printable page is light in dark mode
    Given darkMode true
    When the print page renders
    Then its root has a white background and dark text
```
